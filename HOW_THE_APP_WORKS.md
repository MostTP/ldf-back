## 🎯 Overview

LDF is a financial platform that combines:
- **Referral/MLM System**: Users earn through referrals and team building
- **Investment Pools**: Capital Pool slots and Global Pool for passive income
- **Matrix Structure**: 5-level team hierarchy with bonuses
- **Agent Network**: Coupon-based activation system

---

## 👤 User Registration & Onboarding

### Registration Flow

1. **User Signs Up** (`/auth/register`)
   - Provides: firstName, lastName, email, phone, username, password
   - Optional: `sponsor` (username/code), `couponCode`
   - Bank details required (can be placeholder)
   - Terms & risk disclosure acceptance

2. **Account Creation**
   - Password hashed with bcrypt (10 rounds)
   - Email verification token generated (24hr expiry)
   - User created with `emailVerified: false`, `isPremium: false`

3. **Auto-Activation (if coupon provided)**
   - If `couponCode` provided during registration
   - Automatically activates user (see [Activation System](#activation-system))
   - Otherwise, user must activate manually later

4. **Email Verification**
   - User receives verification email with token
   - Click link or use `/auth/verify-email` endpoint
   - Sets `emailVerified: true`

## 🎫 Activation System

### What is Activation?

Activation is when a new user pays **₦50** using a **coupon code** to join the platform. This triggers the entire earnings distribution system.

### Activation Flow

1. **User Provides Coupon Code**
   - Via registration form OR
   - Via `/activate` endpoint after registration

2. **Coupon Validation**
   - Checks if coupon exists and is unused
   - Coupon must be generated by an Agent

3. **Activation Payment** (₦50)
   - User pays ₦50 (handled via payment gateway)
   - Coupon marked as `isUsed: true`
   - User account activated

4. **Automatic Payout Distribution** (`triggerActivationPayouts`)
   
   When a user activates, **₦2,500** is distributed automatically:
   
   ```
   ₦50 (activation fee) → Distributed as:
   ├─ ₦2,500 → Direct Referrer (REFERRAL_BONUS)
   ├─ ₦1,000 → Global Pool (GLOBAL_POOL_CONTRIBUTION)
   ├─ ₦500  → Operations Cost (OPERATIONS_COST)
   └─ ₦500  → Matrix Bonuses (5-level upline)
       ├─ Level 1: ₦200 (sponsor's sponsor)
       ├─ Level 2: ₦100
       ├─ Level 3: ₦70
       ├─ Level 4: ₦60
       └─ Level 5: ₦70
   ```

### Matrix Bonus Distribution

Matrix bonuses go to the **upline hierarchy** (not direct referrals):
- **Level 1**: User's sponsor's sponsor (₦200)
- **Level 2**: Sponsor's sponsor's sponsor (₦100)
- **Level 3**: 4th level up (₦70)
- **Level 4**: 5th level up (₦60)
- **Level 5**: 6th level up (₦70)

**Example:**
```
User A → User B → User C → User D → User E → User F
         ↑        ↑        ↑        ↑        ↑
      Sponsor  Level 1   Level 2   Level 3   Level 4
```

When User A activates:
- User B gets ₦2,500 (REFERRAL_BONUS)
- User C gets ₦200 (MATRIX_LEVEL_1)
- User D gets ₦100 (MATRIX_LEVEL_2)
- User E gets ₦70 (MATRIX_LEVEL_3)
- User F gets ₦60 (MATRIX_LEVEL_4)
- User G (if exists) gets ₦70 (MATRIX_LEVEL_5)

## 💰 Earnings System

### Earnings Types

The platform tracks multiple earning types:

1. **REFERRAL_BONUS** (₦2,500)
   - Earned when your direct referral activates
   - One-time payment per activation

2. **MATRIX_LEVEL_X** (₦100, ₦70, ₦60, ₦70, ₦200)
   - Earned from upline matrix bonuses
   - 5 levels of matrix earnings

3. **GLOBAL_POOL_ROI**
   - Monthly distributions from Global Pool
   - Only for eligible users: (AFFILIATE INCOME + GLOBAL_POOL_ROI) < ₦10,000
   - Credits exact amount needed to bring total to ₦10,000

4. **PREMIUM_ROI**
   - Quarterly ROI from Capital Pool investments
   - 10% of total investment per quarter
   - Only for premium users with investments

5. **DETTY_DECEMBER**
   - Special seasonal bonus
   - One-time or periodic bonuses
   - Amount varies

6. **GLOBAL_POOL_CONTRIBUTION**
   - NOT a user earning (pool funding)
   - Tracked for audit purposes
   - ₦1,000 per activation goes to pool

7. **OPERATIONS_COST**
   - NOT a user earning (internal tracking)
   - ₦500 per activation for operations

### Balance Calculation

User balance = **Sum of all earnings** - **Sum of all withdrawals**

Earnings are automatically added to balance when created.

## 🌳 Matrix/Team System

### Team Structure

**Direct Referrals**: Users you directly referred (sponsorId = your ID)
**Total Team Size**: All users in your downline (recursive)
**Spillover**: Team size - Direct referrals (indirect referrals)

### Matrix Levels

Matrix progression based on **direct referrals**:

| Level | Direct Referrals Required | Max Slots (shown as current/total) | Bonus per Activation |
|-------|---------------------------|------------------------------------|---------------------|
| Level 1 | 0-1 | 0/5 slots | ₦100 |
| Level 2 | 2-3 | 0/25 slots | ₦70 |
| Level 3 | 4-7 | 0/125 slots | ₦60 |
| Level 4 | 8-15 | 0/625 slots | ₦70 |
| Level 5 | 16+ | 0/3125 slots | ₦200 |

**Note**: Matrix bonuses are earned from **upline** (not your direct referrals). When someone in your upline's downline activates, you get a matrix bonus based on your level.

### Matrix Progression Display

Dashboard shows:
- Current matrix level
- Slots filled in current level
- Progress to next level
- Status: Locked / Current / Completed

## 💎 Investment Systems

### 1. Capital Pool Slots (Premium Investment)

**What it is**: High-yield investment slots at ₦10,000 per slot

**How it works**:
1. User purchases slots (1 or more)
2. Each slot = ₦10,000 investment
3. Each slot tracked as separate `PREMIUM` investment record
4. User upgraded to `isPremium: true`

**ROI Distribution**:
- **Quarterly**: 10% of total investment
- Example: 5 slots (₦50,000) → ₦5,000 quarterly ROI
- Distributed via cron job every 3 months

**Benefits**:
- 10-20% monthly ROI potential
- Fully passive income
- No referral requirement
- Multiple slots = multiplied returns

### 2. Global Pool (Safety Net)

**What it is**: Community-driven profit sharing pool

**Funding**:
- ₦1,000 from each user activation
- Tracked as `GLOBAL_POOL_CONTRIBUTION`

**Eligibility**:
- Must have `emailVerified: true`
- **Current Lifetime AFFILIATE INCOME + Current Lifetime GLOBAL_POOL_ROI must be < ₦10,000**

**Distribution**:
- **Monthly** via cron job
- Credits **exact amount** needed to bring user's total to ₦10,000
- Formula: `Credit Amount = ₦10,000 - (AFFILIATE INCOME + GLOBAL_POOL_ROI)`
- Distributed as `GLOBAL_POOL_ROI` earnings
- Only distributes if pool has sufficient funds

**Example**:
- User has ₦3,000 AFFILIATE INCOME + ₦2,000 GLOBAL_POOL_ROI = ₦5,000 total
- System credits exactly ₦5,000 to bring total to ₦10,000
- User now has ₦10,000 total (₦3,000 AFFILIATE + ₦7,000 GLOBAL_POOL)

## 🌊 Global Pool System

### Pool Management

**Contributions** (`GLOBAL_POOL_CONTRIBUTION`):
- ₦1,000 per user activation
- Not counted as user earnings
- Accumulates in pool

**Distributions** (`GLOBAL_POOL_ROI`):
- Monthly distributions to eligible users
- Counted as user earnings
- Added to user balance

**Pool Calculation**:
```
Total Pool = Sum of all GLOBAL_POOL_CONTRIBUTION
Distributed = Sum of all GLOBAL_POOL_ROI
Available = Total Pool - Distributed
```

### Distribution Logic

1. Get all users with `emailVerified: true`
2. For each user, calculate: `AFFILIATE INCOME + GLOBAL_POOL_ROI`
3. Filter to users where combined total **< ₦10,000**
4. For each eligible user, calculate: `Credit Amount = ₦10,000 - Combined Total`
5. Distribute credits (up to available pool funds) to bring each user to exactly ₦10,000
6. Create `GLOBAL_POOL_ROI` earning for each user
7. Update user balances

### Admin Controls

- View pool stats: `GET /admin/global-pool/stats`
- Manual distribution: `POST /admin/global-pool/distribute`

## 💳 Wallet & Withdrawals

### Balance Management

**User Balance**:
- Stored in `user.balance` field
- Calculated as: `Total Earnings - Total Withdrawals`
- Auto-incremented when earnings created
- Auto-decremented when withdrawal processed

**Withdrawable Amount**:
- Current balance (if ≥ minimum)
- Minimum withdrawal: ₦5,000

### Withdrawal Flow

1. **User Requests Withdrawal**
   - Must have balance ≥ ₦5,000
   - Must have KYC verified (`kycVerified: true`)
   - Must have bank details set

2. **Withdrawal Created**
   - Status: `PENDING`
   - Balance NOT deducted yet

3. **Admin Processes** (or auto in dev mode)
   - Status: `APPROVED`
   - Payment gateway processes transfer
   - Status: `PAID` (or `FAILED`)
   - Balance deducted when `PAID`

4. **Transaction History**
   - All withdrawals tracked
   - Status updates visible to user

### Withdrawal Statuses

- `PENDING`: Request submitted, awaiting processing
- `APPROVED`: Approved, payment processing
- `PAID`: Successfully transferred
- `FAILED`: Transfer failed

## 🎟️ Agent System

### What is an Agent?

Agents can generate **coupon codes** that users redeem for activation.

### Agent Features

1. **Coupon Generation**
   - Generate multiple coupons at once
   - Each coupon = 1 activation
   - Coupons cost ₦100 each (agent pays)

2. **Coupon Management**
   - View all generated coupons
   - See which coupons are used/unused
   - Track who used each coupon

3. **Agent Coupon Credits**
   - Agents purchase credits (₦100 per credit)
   - 1 credit = 1 coupon generation
   - Credits stored in `agentCouponCredits` field

### Agent Flow

1. **Upgrade to Agent** (admin only)
   - Admin sets `isAgent: true`
   - Agent can now generate coupons

2. **Purchase Credits**
   - Agent buys credits (₦100 per credit)
   - Credits added to `agentCouponCredits`

3. **Generate Coupons**
   - Uses 1 credit per coupon
   - Coupon code generated
   - User can redeem for activation

4. **User Redeems Coupon**
   - User activates with coupon
   - Coupon marked as used
   - Activation payouts triggered

## ⏰ Cron Jobs & Automation

### 1. Global Pool ROI Distribution

**Frequency**: Monthly
**Function**: `distributeGlobalPoolROI()`

**What it does**:
- Calculates available pool
- Finds eligible users: (AFFILIATE INCOME + GLOBAL_POOL_ROI) < ₦10,000
- Credits exact amount to bring each user to ₦10,000 (up to available pool)
- Creates `GLOBAL_POOL_ROI` earnings

### 2. Premium ROI Distribution

**Frequency**: Quarterly (every 3 months)
**Function**: `distributePremiumROI()`

**What it does**:
- Finds all premium users with investments
- Calculates 10% ROI per user
- Creates `PREMIUM_ROI` earnings
- Updates user balances

### Cron Job Setup

Cron jobs should be configured to run:
- Global Pool: 1st of every month
- Premium ROI: Every 3 months (Jan, Apr, Jul, Oct)

## 🎯 Key Concepts Summary

### Direct Referrals vs Matrix Levels

- **Direct Referrals**: People you directly referred
- **Matrix Levels**: Your position in upline hierarchy
- You earn from BOTH:
  - Direct referrals → REFERRAL_BONUS
  - Upline activations → MATRIX_LEVEL bonuses

### Investment vs Earnings

- **Investments**: Money you put in (Capital Pool slots)
- **Earnings**: Money you receive (bonuses, ROI)
- **Balance**: Earnings - Withdrawals

### Global Pool vs Capital Pool

- **Global Pool**: Community pool, eligibility-based
- **Capital Pool**: Personal investment, slot-based
- Both provide passive income
- Different eligibility and ROI structures
